# GitHub 开源安卓应用推荐 · 3,424 款 Android 软件

按用途收录 **3,424 款应用、140 个小类**。找刷机工具、冷门好玩的安卓软件、影音播放器、开源游戏、文件传输或本地 AI，可以先逛下面的精选，也可以直接点分类。

- **[韦诺之战](https://f-droid.org/packages/org.wesnoth.Wesnoth/)** · 奇幻六角格回合战棋。招募士兵、占村拿收入、利用森林和山地防守。单位会累积经验并升级，战役后面还可召回练出的老兵。 可以单人打剧情战役，也能在线或同机轮流对战。想玩有养成和战役的正经战棋，先试这款。 [GitHub](https://github.com/wesnoth/wesnoth)
- **[Mindustry](https://f-droid.org/packages/io.anuke.mindustry/)** · 开矿、铺传送带、接生产线，把资源送给炮塔和部队，同时守住一波波敌人。 产线能不能供上前线会直接影响战局。喜欢工厂布局又嫌纯经营节奏慢的可以试。 [GitHub](https://github.com/Anuken/Mindustry)
- **[Look4Sat](https://f-droid.org/packages/com.rtbishop.look4sat/)** · 根据位置预测卫星过境，查看什么时候出现、从哪边升起。 想看卫星或用便携电台跟踪时，可以提前选过境窗口。 [GitHub](https://github.com/rt-bishop/Look4Sat)
- **[whoBIRD](https://f-droid.org/packages/org.woheller69.whobird/)** · 用手机麦克风识别周围的鸟鸣，并给出可能的鸟种。 遛弯时听见叫声就有线索，适合顺手认识本地鸟类。 [GitHub](https://github.com/woheller69/whoBIRD)
- **[Trail Sense](https://f-droid.org/packages/com.kylecorry.trail_sense/)** · 用手机传感器做户外方位与环境辅助，常见用途有指南针、定位标记和气压数据。 徒步时能把几种常用读数放在一个应用里，很多功能可以离线用。 [GitHub](https://github.com/kylecorry31/Trail-Sense)
- **[LocalSend](https://f-droid.org/packages/org.localsend.localsend_app/)** · 让同一局域网内的安卓、Windows 和其他兼容设备互传文件。 公司电脑与手机连同个路由时，可直接传图和视频，免去云盘中转。 [GitHub](https://github.com/localsend/localsend)
- **[Image Toolbox](https://github.com/T8RIN/ImageToolbox/releases)** · 把图片裁切、格式转换、压缩、画板和批量处理放进一个安卓应用。 常做产品图时可以在手机一次处理多张图和文件格式，少来回切应用。 [GitHub](https://github.com/T8RIN/ImageToolbox)
- **[Syncthing-Fork](https://f-droid.org/packages/com.github.catfriend1.syncthingfork/)** · 让手机和电脑或 NAS 之间同步选定文件夹，设备之间直接交换文件。 截图、电子书或笔记目录自动同步，适合长期在 Windows 和安卓来回切换。 [GitHub](https://github.com/researchxxl/syncthing-android)
- **[Key Mapper](https://f-droid.org/packages/io.github.sds100.keymapper/)** · 重新绑定安卓设备的音量键、外接键盘等输入，并关联快捷动作。 想用按键快速启动常用功能，或给外接设备设置操作习惯时值得试。 [GitHub](https://github.com/keymapperorg/KeyMapper)
- **[MA PDF](https://f-droid.org/packages/com.vayunmathur.pdf/)** · PDF viewing app [GitHub](https://github.com/vayun-mathur/Modern-Apps)
- **[phyphox](https://f-droid.org/packages/de.rwth_aachen.phyphox/)** · 把手机的加速度计、陀螺仪、磁力计等变成实验测量工具。 闲置安卓机也能当实验数据记录仪，能做机械运动和声音类实验。 [GitHub](https://github.com/phyphox/phyphox-android)
- **[Robot36](https://f-droid.org/packages/xdsopl.robot36/)** · 把 SSTV 音频信号解码成图像。 有人发一段匹配制式的啸叫音频时，可拿安卓手机听声还原成图片。 [GitHub](https://github.com/xdsopl/robot36)
- **[AndrOBD](https://f-droid.org/packages/com.fr3ts0n.ecu.gui.androbd/)** · 通过兼容的 OBD-II 适配器读取汽车支持的实时车辆数据。 手里有兼容蓝牙适配器时，可以把手机当临时仪表或用来对照车辆读数。 [GitHub](https://github.com/fr3ts0n/AndrOBD)
- **[RikkaHub](https://github.com/rikkahub/rikkahub/releases)** · 集中配置多家大模型服务和模型，在安卓上发起对话。 已经有多个 API 服务时，可在同一套聊天界面切模型。 [GitHub](https://github.com/rikkahub/rikkahub)
- **[Shattered Pixel Dungeon](https://f-droid.org/packages/com.shatteredpixel.shatteredpixeldungeon/)** · 像素地牢 Roguelike。下地牢搜药水、卷轴与装备，用走位、道具和地形解决随机碰到的敌人。 死了就开新一局，摸清鉴定、消耗品和职业机制后重玩性很强。 [GitHub](https://github.com/00-Evan/shattered-pixel-dungeon)
- **[Catima](https://f-droid.org/packages/me.hackerchick.catima/)** · 把会员卡、购物折扣卡和票券上的条码收进安卓应用。 结账时直接找到条码，不用每次翻不同品牌的小程序。 [GitHub](https://github.com/CatimaLoyalty/Android)
- **[Birday - Birthday Manager](https://f-droid.org/packages/com.minar.birday/)** · yet useful birthday manager. Birday is free and ad-free! 🥳 [GitHub](https://github.com/m-i-n-a-r/birday)
- **[OpenTTD](https://f-droid.org/packages/org.openttd.fdroid/)** · 运输经营模拟。修铁路、公路和车站，让乘客和材料在城市与工厂之间周转。 玩着玩着就会开始琢磨信号、站台和路线堵塞，适合喜欢搭交通网的人。 [GitHub](https://github.com/n-ice-community/commandergenius)
